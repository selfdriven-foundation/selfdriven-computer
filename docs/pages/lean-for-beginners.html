The premise

In Lean, a proof is code the computer checks.

Tests show code worked for the inputs someone tried. In Lean you state a claim that must hold for every input, then write a proof. A small trusted kernel checks each step, so a gap in the reasoning can't slip through.

The same language runs programs. AWS uses it to model Cedar, its authorisation policy language, and prove its security properties. Mathematicians use it to check research proofs.

Lean checks the proof. You still choose the claim.

Learn to read a theorem

Write programs

Lean is a functional language. You define functions with def, run them with #eval and compile them to native code.

  • def
  • #eval
  • lake build

State claims

A claim is a type in Prop. A theorem gives it a name and a statement, such as p ∧ q → q ∧ p.

  • Prop
  • theorem
  • ∀ and ∃

Prove them

Tactics change the goal one step at a time until none are left. The kernel then checks the finished proof again.

  • tactic
  • goal
  • kernel

Read Lean

Tap each part of a theorem.

Every theorem has the same shape: a name, what it talks about, a colon, the claim, then the proof. Tap a part to see what it means.

Logic and programs line up.

This match is called the Curry–Howard correspondence. It's why one language can run code and check proofs.

    Getting started

    From the browser to your own project.

    Try everything on this page in the browser first. When you want more, install the editor tools. They manage Lean versions for you, so each project gets the version it needs.

    1. 01 · Browser

      Try it live

      Open the Lean playground, paste a proof from this page and watch the infoview update as you type.

      live.lean-lang.org
    2. 02 · Editor

      Install VS Code and Lean 4

      The recommended setup is VS Code with the Lean 4 extension. Its setup guide installs elan, Lean's version manager.

      lean-lang.org/install
    3. 03 · Project

      Create a project

      Lake is Lean's build tool. For maths, create a Mathlib project from the ∀ menu in VS Code instead.

      lake new hello && cd hello && lake build
    4. 04 · Practise

      Play the Natural Number Game

      Build addition and multiplication from scratch, one level at a time, with hints along the way. It's the classic first step into proving.

      adam.math.hhu.de

    Prefer a terminal on Linux or macOS? Install elan directly, then open a new terminal:

    curl https://elan.lean-lang.org/elan-init.sh -sSf | sh
